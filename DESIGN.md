# Local report design

A reading and filtering surface for one captured analysis, usable offline on desktop or mobile. Use a light slate background with white tables, dark navy text, and a restrained cobalt control accent. System sans is the reading face; tabular numbers align comparisons. No remote fonts, images, analytics or network calls.

The question and capture scope lead. Topic totals describe the whole report; an explicitly separate post filter narrows the post table, never silently recomputes a full-report unique-account metric from summed post counts. Evidence opens inline at the relevant post. Labels, keyboard focus, empty results and reset are first-class states. Small screens scroll wide tables inside labelled containers without widening the document.

Verification: synthetic desktop/mobile browser captures; keyboard and filter behavior; aggregate/identified/pseudonymous export isolation. This file is development guidance and is not embedded in generated reports.

Verified on the synthetic report at 1280×900 and 390×844: no document-wide horizontal overflow, working keyboard focus, search/topic filters, empty results, date validation and inline evidence.
