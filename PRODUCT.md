# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
The approved deliverable is a locally generated HTML report within an existing Codex/Claude skill. Static HTML/CSS/JavaScript and a Python standard-library analysis helper; no hosted app or browser collector service.

## Users and purpose
The user selected content-topic comparison, clickable reports, and comment/like cross-analysis. An agent observes accessible Instagram data with its permitted computer/browser tools, then computes evidence-aware comparisons. Export is requested separately from ordinary in-chat analysis.

## Constraints
No account credentials or live browser capability are bundled. Aggregate export is the default. Stable IDs and provisional handle matches remain separate; incomplete data cannot establish absence. All demonstrations in the repository use synthetic accounts.
